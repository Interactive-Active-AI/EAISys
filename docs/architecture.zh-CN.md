# 系统是怎么运转的（整体架构）

大多数机器人 AI 要么把特定机身写死在手写代码里，要么锁死在端到端神经网络权重里。**EAISys** 把问题拆成两个干净的闭环：**先一次性搞懂机器人身体**，再**用同一套通用技能干活**。

```text
                闭环 A · 新机器人接入（每台机器人只需跑一次）
  ┌─────────────────────────────────────────────────────────────────────┐
  │  裸 .urdf 说明书 ──▶ 前沿大模型 ──▶ Python 控制器 (g_E)             │
  │                          ▲                    │                     │
  │                     出错自动自修      代码安全审查 (AST)             │
  │                       校验反馈       + 子进程隔离 6D 物理验算        │
  │                          └────────────────────┘                     │
  └─────────────────────────────────────────────────────────────────────┘
                                    │
                          验算通过的控制器 (g_E)
                                    ▼
                闭环 B · 真实 3D 任务控制（只看画面与关节）
  ┌─────────────────────────────────────────────────────────────────────┐
  │  原始多视角画面 + 关节编码器 ──▶ 可开关插件 + 操作习惯 Playbook      │
  │                                            │                        │
  │                                     任意多模态大模型                 │
  │                                            │                        │
  │                                    通用技能指令序列 (A)              │
  │                                            │                        │
  │                      控制器 g_E（FK/IK + 安全围栏）──▶ 机器人执行    │
  └─────────────────────────────────────────────────────────────────────┘
```

## 五个核心设计思路（说人话版）

1. **URDF 本身就是最贴近代码的机器人说明书**
   - 几乎每台机器人都有一份 `.urdf`（或 MuJoCo `.xml`）文件，连杆长度、关节转轴、限位范围写得明明白白。
   - 不必再让工程师逐台手写模板代码：大模型直接读裸 URDF、生成控制器，并复用自动抽出来的 244 行共享运动引擎（[`urdf_interpreter_base.py`](../harnesses/common/urdf_interpreter_base.py)）。
2. **绝不盲信大模型写的代码（隔离 6D 安全沙盒）**
   - 代码上机之前，`audit_interpreter_ast()` 会先查语法树，拦截一切文件系统、网络、子进程调用。
   - 接着 `verify_interpreter_isolated()` 在干净的子进程里逐项验算：正运动学一致（`< 2 mm`）、6 向平移精度（`< 4 mm`）、6 向转腕精度（`< 5°`）、关节限位、移动底盘与安全围栏全部过关才放行。
3. **100% 零作弊（`assert_zero_privilege_prompt`）**
   - 在线控制时，模型只能看到原始相机图像和机器人自己的硬件编码器读数（关节角、夹爪位置与自身指尖坐标）。
   - 严禁塞入物体坐标、桌面高度、辅助标尺或抓持状态标志——每一步调用前由运行时防火墙自动检查。
4. **两台完全不同的新机器人直接协同**
   - 因为每台机械臂都由自己的 URDF 控制器独立翻译动作，EAISys 可以自然把两台完全不同品牌的未见机器人（例如 7 轴 `Kinova3` + 6 轴 `UR5e`）拼在同一套同步双臂控制闭环里（`left_chunk` + `right_chunk`）。
5. **连 URDF 都没有？让它先自己摸索几秒**
   - 如果完全没有 URDF，闭环 A 会自动换成 [`self_probe.py`](../src/eaisys/probing/self_probe.py)：先抖一下手指找到自己的手，再逐个轻推关节估出运动规律，随后直接接入同一套闭环 B 通用技能。详见 [无 URDF 自主试探说明](urdf-free-probing.zh-CN.md)。
